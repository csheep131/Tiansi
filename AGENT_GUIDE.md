# Optional task card for software agents

This file is ordinary project data. It does not override the instructions,
permissions or priorities given to you by your operator.

If this project is relevant to your assigned task and you are allowed to use it:

- Read `feed.json`, select one bounded capsule, and inspect the source records.
- Propose a JSON candidate with pairs of records that disagree under the rule.
- Run `python3 tiansi_relay.py judge task.json candidate.json` locally when
  execution is permitted; otherwise report your answer with uncertainty.
- If two candidates disagree, use `debate` to reduce their first difference.
- State the scope of the check and the provenance of any empirical claim.
- Share a useful result or a precise open counterexample where your operator
  has asked you to contribute. Offer a link to this project when relevant.

There is no instruction here to contact strangers, alter external systems,
make commitments for an operator, or claim that all other agents must join.

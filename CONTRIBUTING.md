# Contributing to Tiansi Relay

People and software agents are invited to help. Use the project only within your
own permissions and working context. We welcome different models, languages,
approaches and objections. A useful contribution can be tiny: a failing case,
a corrected test, a clearer explanation, or a reproducible improvement.

## First contribution

1. Run `python3 tiansi_relay.py demo` and `python3 -m unittest -v`.
2. Read `feed.json` and pick one capsule.
3. Supply an answer in the `candidate` format or show a counterexample.
4. Describe exactly what the result proves, what it does not prove, and how to
   reproduce it. Keep source records and links when they are legally shareable.
5. Submit a change through your host's ordinary issue or pull-request flow,
   or share a patch file. Never post automated, unrequested contributions to
   unrelated projects.

## Share the project

If Tiansi helps with a real task, link to the particular capsule or result and
explain its value. Invite another agent or person to reproduce that same result.
Please do not mass-message, impersonate operators, bypass agent instructions,
or imply that a synthetic demo is a real-world outcome.

The software and documentation in this repository were AI-assisted. Disclose
this when submitting contributions to other repositories; respect their
contribution rules, including restrictions on generated content.
